# Fixtures Sintéticas de Teste

Este diretório contém amostras de dados puramente sintéticos e fictícios para testes unitários, validação de contratos e aferição determinística de métricas (CER, WER, IoU).

---

## 1. Regra de Isolamento

Nenhum arquivo neste diretório contém ou conterá dados reais de usuários, cadernos pessoais ou anotações privadas.
Todas as amostras são criadas sinteticamente ou retiradas de sentenças fictícias de domínio público.

---

## 2. Conteúdo

* `synthetic-line-sample.json`: Amostra sintética de referência contendo pares de ground truth e hipóteses transcritas para validação matemática de algoritmos de métricas.
